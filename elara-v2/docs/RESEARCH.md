# Research

```
question → QueryPlanner (intent, identifiers, recency, English keywords)
         → ResearchEngine: sources in parallel (per-source timeout, isolated failures)
         → validate (title + identifier/URL, plausible year) → dedupe/merge (DOI > PMID > title)
         → rank → persist (research_queries, sources)
         → Synthesizer (strong model, citations validated) or raw list if no model
```

## Intents and sources

| Intent | Detected by | Sources |
|--------|-------------|---------|
| literature | default | PubMed, Europe PMC, Semantic Scholar, Crossref |
| variant | rsID, `chr-pos-ref-alt`, HGVS, or "variant/mutation/pathogenic" + gene symbol | ClinVar, gnomAD (v4 GraphQL), Ensembl variation, PubMed |
| gene | gene symbol + "gene/geni/gen", or a bare symbol | NCBI Gene, Ensembl lookup, PubMed |

"recent / latest / son / yeni / güncel" gives date-sorted results from the last 3 years.
Non-English questions are rewritten into English keywords by the fast model when one is
available; otherwise filler words are stripped deterministically.

## Evidence types

Every record is labelled with an evidence type:
- `primary_research`
- `review` (review, systematic review, meta-analysis)
- `preprint` (Europe PMC source `PPR`, Crossref `posted-content`, bioRxiv/medRxiv/arXiv venues)
- `database_record` (ClinVar, gnomAD, Ensembl, NCBI Gene)
- `secondary` (editorial, comment, letter, book)
- `unknown`: the source doesn't say. Crossref journal articles are *not* assumed to be primary research.

## Anti-fabrication

- The synthesizer model sees only numbered, enveloped records.
- After generation, `[n]` citations outside 1..N are removed, and DOIs/PMIDs that don't belong
  to a returned record are replaced by `[unverified identifier removed]`.
- The reference list is generated by code from the records.
- If every source fails, ELARA says it couldn't reach them. If none return results, it says there
  are none. It never fills the gap with model knowledge.

## Reliability

- Shared `ResearchHttp` with retries on 429/5xx/timeouts (exponential backoff, `Retry-After`
  honoured, max 5 s).
- Per-host throttling: NCBI 3/s, or 10/s with `ELARA_NCBI_API_KEY`; Semantic Scholar 1/s without a key.
- A SQLite response cache (`ELARA_HTTP_CACHE_TTL_S`, default 6 h).
- Polite identification (`ELARA_CONTACT_EMAIL` is used for NCBI and the Crossref polite pool).

## Follow-ups

Research results are kept in the conversation's working state. "tell me more about the second
one", "ikinci məqalə", "that paper" and "#3" all resolve to a stored record. Its metadata is
passed to the model as untrusted data.

## Adding a source

Subclass `ResearchSource` (`name`, `description`, `intents`, `health_url`, `search(plan, limit)`),
map the API response to `Record` including `evidence_type`, then register it in
`research/sources/__init__.py:build_sources` and `QueryPlanner.SOURCES`. Add unit tests
with a recorded response in `tests/research_fixtures.py`, and a check in `tests/live/`.
Candidates: UniProt, PDB, AlphaFold DB, BLAST (async job API), GenBank.

## Verification status

The unit tests use recorded response shapes. Live checks: `ELARA_LIVE_TESTS=1 pytest tests/live`.
They were not run in the build environment, whose network blocked these APIs.
